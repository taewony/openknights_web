## DB tasklist 
- 'ADMIN' role을 가진 user가 로그인하면 우측 상단에 'DB migration' 버튼을 보여준다.
- users : 변경 사항 없음. 참여하고 있는 project는 name 으로 lookup

- contests : 현재 term 만으로 구분하고 있는데, term 필드외에 typedTerm 필드 추가.
  - typedTerm은 'swopen-2025-1st', 'swcreate-2025-2nd'와 같이 어떤 경진대회인지도 포함한 string으로 저장한다.

- projects : project가 속한 contest를 찾기 위해 typedTerm 필드도 추가하여 저장한다.

## UI tasklist
- dropdown menu로 변경하여, typedTerm 선택하면 현재 선택된 특정 경진대회가 표시되게 한다.
  이 상태에서 project를 누르면 해당 경진대회에 신청된 project만 보여 준다.

## 추가 기능
1) CSV 파일 처리
  - 일정
  - 성적 (score)
  - project detail data

2) 경진대회 대시보드
  - 대표 공지사항 표시 (DB에서 일정 읽어 표시, ## 제목, ### 제목)
  - 전체 일정 표시 (DB에서 일정 읽어 표시)
  - 예선 상황 (DB에서 읽어 상태 표시)
  - 본선 상황
  - 입상 상황

3) 공지글 등록 기능
  - ADMIN role 로그인 시 기능 허용
